# 基于机器学习的 JAK1 细胞因子信号激酶构效关系挖掘与解析

> 以 JAK1 在细胞因子信号中的广泛角色为对象，挖掘并解析其构效关系，为免疫炎症性疾病靶点研究提供数据驱动视角。

## 一、方法

- **模型**：D-MPNN 有向消息传递神经网络（Chemprop 式）

- **输入**：分子图（原子节点 + 化学键边，RDKit 解析 SMILES 得到）
- **训练规模**：10222 条样本，2 类
- **标签协议**：rel
- **验证**：5 折分层交叉验证 × 3 随机种子 = 15 次独立训练
